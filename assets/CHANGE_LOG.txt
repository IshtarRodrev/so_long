style reference provided in Modern Office Top-Down Interrior Map.png
general requirements (to be adjusted if nessesary):
- Style: Pixel Art
- Theme: Modern / Office / Interior
- Perspective: Top-Down
- Format: PNG
- Resolution: 512x512 pixel
- One single square game tile: the image is the tile itself, filled edge to edge, with no border, frame or margin
- Use the style reference only for the style and camera angle, and draw nothing else from it
- Crisp, hard-edged large square pixels, flat colours and simple bold shapes that stay readable at 40x40 pixels
- Any floor is flat, uniform grey in colour #505050 with no texture
- No shadows, text, people or watermarks

Every prompt below already contains the requirements above. Attach what it says and paste everything under PROMPT.
If a requirement changes, every prompt has to change with it.
Note: a prompt cannot set the file format or the exact size, the tool decides those. If your tool has PNG and 512 settings, use them. Anything else must be converted to a square PNG before the game can use it.
